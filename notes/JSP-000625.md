## Statement and counting convention

For A ⊆ ℕ (where ℕ includes zero), let

\[
r_A(n)=\#\{(a,b)\in A\times A:a+b=n\},\qquad
S_A(N)=\sum_{n=0}^{N}r_A(n).
\]

Pairs are ordered: off-diagonal pairs occur twice and diagonal pairs once. The Lean definition counts first coordinates `a ∈ Finset.range (n+1)` satisfying `a ∈ A ∧ n-a ∈ A`; the unique second coordinate is `n-a`. The bound `a≤n` prevents truncated natural subtraction from introducing extra representations. `representation_eq_card_antidiagonal_filter` and `cumulative_eq_card_pairs` formally verify the pair-count interpretation.

This is exactly the convolution `1_A ∗ 1_A` convention on [Erdős problem 763](https://www.erdosproblems.com/763). The original Erdős–Fuchs paper explicitly calls it convention (I) on p. 69. It is not the unordered function `(f(z)^2+f(z^2))/2`.

The main theorem in `units/jsp/lean/JSP000625.lean` is:

```lean
theorem erdos_fuchs_bounded_error :
    ∀ A : Set ℕ, ∀ c : ℝ, 0 < c →
      ¬ ∃ C : ℝ, ∀ N : ℕ,
        |(cumulative A N : ℝ) - c * (N : ℝ)| ≤ C
```

Here `cumulative A N : ℕ` is exactly the finite sum from 0 through N. The absence of an explicit `C≥0` assumption is intentional: any alleged bound forces it, already at N=0. A uniform C is equivalent to eventual O(1), since finitely many initial exceptions can be absorbed into the constant. Thus the theorem gives precisely the requested negative answer, for every set A and every positive real slope c.

## Published proof followed

For the original convention and historical theorem: P. Erdős and W. H. J. Fuchs, “On a problem of additive number theory,” *J. London Math. Soc.* 31 (1956), 67–73, [PDF](https://users.renyi.hu/~p_erdos/1956-07.pdf).

The formalization specializes Newman's finite geometric multiplier argument to bounded discrepancy. It retains the exact `c*z/(1-z)` term for our convention `S(N)=cN+E(N)`; Newman's shifted convention gives `c/(1-z)`. It replaces his explicit logarithmic kernel bound by an elementary consequence of Parseval and dominated convergence. The multiplier, integer-coefficient lower bound, and Cauchy–Schwarz estimate are the published argument, not a purported real-variable substitute.

The stronger historical statement on erdosproblems.com uses **little-o**, whereas the supplied prompt wrote big-O. This work proves only the requested O(1) version and makes no stronger endpoint claim.

## Proof

Suppose `|S_A(N)-cN|≤C` for all N, with c>0. Let

\[
f(z)=\sum_{a\in A}z^a,\quad E(z)=\sum_{N\ge0}(S_A(N)-cN)z^N,
\quad H_m(z)=\sum_{j<m}z^j.
\]

All series converge absolutely for |z|<1. Cauchy multiplication and the prefix-sum identity give the exact formula

\[
f(z)^2=\frac{cz}{1-z}+(1-z)E(z).
\]

For real 0≤t<1, `|f(t)^2-ct/(1-t)|≤C`. Since f(t)≥0,

\[
\sqrt{1-t}\,f(t)\longrightarrow\sqrt c\quad(t\to1^-).
\]

Write normalized Haar integration on the unit circle as an average, and set z=r e(x). The coefficients b_n of `fH_m` are natural numbers, so `b_n²≥b_n`. Parseval gives

\[
f(r^2)H_m(r^2)\le\int|f(z)H_m(z)|^2.
\]

On the other hand, `(1-z)H_m(z)=1-z^m`, `|H_m(z)|≤m`, and `|1-z^m|≤2`. Therefore

\[
|f(z)H_m(z)|^2\le\frac{cm^2}{|1-z|}+2|E(z)||H_m(z)|.
\]

By Parseval and Cauchy–Schwarz,

\[
\int|E(z)|^2\le\frac{C^2}{1-r^2},\qquad
\int|H_m(z)|^2\le m,
\]

and consequently, with `J(r)=∫|1-r e(x)|⁻¹`,

\[
f(r^2)H_m(r^2)\le cm^2J(r)+\frac{2C\sqrt m}{\sqrt{1-r^2}}.
\]

To justify the needed kernel limit without logarithmic estimates, put
`k_r(x)=sqrt(1-r²)/|1-r e(x)|`. Geometric-series Parseval gives `∫k_r²=1`. Also k_r→0 except at the circle identity, a Haar-null singleton. For any K>0,
`0≤k_r≤min(k_r,K)+k_r²/K`. Dominated convergence sends the first integral to zero; the second is at most 1/K. Thus `∫k_r→0`, equivalently `sqrt(1-r²)J(r)→0`.

Multiply the preceding estimate by `sqrt(1-r²)` and send r→1⁻ with m fixed. The result is

\[
m\sqrt c\le2C\sqrt m\qquad\text{for every }m\in\mathbb N.
\]

Choose m>0 with `mc>4C²`; squaring contradicts this inequality.
